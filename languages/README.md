# The Twelve Languages

Twelve fully constructed tongues, each with its own phonology, grammar, naming conventions, vocabulary, everyday phrases, and idioms. They exist so a People can be *heard*, not just placed on the map.

Written before the LANGUAGE action family had rules. The rules should be built to fit these, not the other way round.

| Language | Root Inspiration |
|---|---|
| 1. Velthari — The Desert Empire Tongue | Classical Arabic / Persian (Farsi) |
| 2. Orishaan — The River Delta Tongue | Yoruba / Igbo / Swahili (West & East African language families) |
| 3. Keldrath — The Mountain Forge Tongue | Georgian / Basque (language isolates with complex consonant clusters) |
| 4. Sylvannë — The Forest Covenant Tongue | Finnish / Welsh (with Celtic mutation echoes and Finnish vowel harmony) |
| 5. Thurzokk — The War Tongue of the Iron Clans | Mongolian / Klingon-design principles (harsh plosives, VSO order) |
| 6. Tessavori — The Merchant Republic Tongue | Italian / Greek (with Latin legal structure) |
| 7. Ul'nakhari — The Tidal Tongue of the Deep Ocean People | Hawaiian / Polynesian (Samoan, Tongan) — minimal consonants, directional system |
| 8. Zhevakand — The Steppe Nomad Tongue | Turkish / Mongolian / Kazakh (agglutinative, vowel harmony, evidentiality) |
| 9. Aelindri — The Celestial Tongue of the Star-Priests | Latin / Sanskrit (classical highly inflected systems with extensive case grammar) |
| 10. Brakthal — The Goblin Tinker Tongue | German compound-word logic + Japanese phonology (CV syllables, particle system) |
| 11. Serethka — The Swamp Dialect of the Marsh Covenant | Russian / Polish / Romanian (Slavic consonant clusters, case system, Balkan features) |
| 12. Namuri — The Island-Hopper Pidgin | Malay / Javanese / Tok Pisin — creole and pidgin design principles |
