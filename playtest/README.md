# Playtest Reports

*Real-play observations and feedback. Each session gets a file.*

## File naming

`YYYY-MM-DD-[age]-[session-number].md`  
e.g. `2026-05-10-age-ii-session-01.md`

## What to capture in each report

- **Players:** who was at the table
- **Age and turn range:** what was played
- **What worked:** mechanics that felt good
- **What dragged:** turns that stalled, rules that confused
- **Kid report:** did the youngest player engage? disengage? Where?
- **AP economy:** did anyone feel AP-starved or AP-flush for too long?
- **Specific mechanic notes:** anything about Complicate, Weave Bonus, Price of Passing, etc.
- **Map state:** what the map looks like at the end of the session (photo if possible)
